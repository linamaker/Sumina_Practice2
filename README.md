# Интерактивная панель управления UI-компонентами
Cozy Yard — персональный игровой дашборд, который объединяет библиотеку пользователя, параметры игрового вечера, систему рекомендаций, информацию об играх, скидки, бесплатные предложения и игровые планы.
Использованные технологии:
- HTML5
- CSS3
- JavaScript
- ES6 Modules
- ООП
- Fetch API
- AbortController
- LocalStorage
- CSS Grid
- Flexbox
- REST API
Дополнительные JavaScript-фреймворки не использовались.
Использование искусственного интеллекта:
При разработке проекта использовался ChatGPT.
ИИ применялся как вспомогательный инструмент для:
- поиска и развития идеи проекта;
- проектирования структуры интерфейса;
- создания визуальной концепции;
- проектирования ООП-архитектуры;
- написания и рефакторинга JavaScript;
- работы с API;
- поиска и исправления ошибок;
- улучшения адаптивности интерфейса.
Пример существенного запроса
Разработать тематический игровой дашборд на чистом JavaScript с использованием ООП и ES6-модулей. Виджеты должны наследоваться от общего UIComponent, иметь независимое состояние и корректно очищать обработчики и запросы. Главная задача приложения — помочь пользователю выбрать игру на вечер из собственной библиотеки с учётом количества игроков, времени и настроения. Необходимо подключить внешние API, предусмотреть состояния загрузки и ошибок, AbortController, localStorage и адаптивный интерфейс.
